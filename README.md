# Análise Avançada de Faturamento em E-commerce (Google BigQuery)

Este repositório contém uma consulta SQL avançada desenvolvida no **Google BigQuery**, utilizando o banco de dados público do e-commerce da The Look (bigquery-public-data.thelook_ecommerce). 

O objetivo da análise é identificar e rankear as categorias de produtos que geraram um faturamento total superior a R$ 50.000 em pedidos concluídos.

## 🛠️ Tecnologias Utilizadas
* **Google BigQuery** (Consulta em nuvem)
* **SQL Avançado** (INNER JOIN, COUNT(DISTINCT), SUM, AVG, ROUND, GROUP BY, HAVING, ORDER BY)
